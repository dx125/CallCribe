# CallCribe on an NVIDIA GPU (CUDA 12).
#
#     pip install -r requirements-gpu.txt
#
# About 700 MB of wheels, which is why this is a separate file: without a
# GPU they are dead weight, and CallCribe runs fine on the CPU without them.
#
# CTranslate2 (the engine behind faster-whisper) needs cuDNN 9 on Windows.
# These wheels drop their DLLs into site-packages/nvidia/*/bin, where
# Windows does not look on its own — callcribe/cuda.py registers those
# folders at startup. No system-wide CUDA toolkit install is required.
#
# If CUDA is missing or broken the app says so and transcribes on the CPU;
# it does not refuse to start.

-r requirements.txt

nvidia-cublas-cu12>=12.1,<13
# cuDNN 9.11 выкинул ядра для Maxwell, Pascal и Volta (sm_50 - sm_70).
# На GTX 10xx с 9.26 модель грузится и подписывается «cuda» — а первая же
# фраза падает с CUDNN_STATUS_EXECUTION_FAILED_CUDART, потому что считать
# нечем. Проверено на GTX 1050 Ti (sm_61). 9.10 умеет и Pascal, и всё
# новое, так что граница не мешает никому.
nvidia-cudnn-cu12>=9.1,<9.11
